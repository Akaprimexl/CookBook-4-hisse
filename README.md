# CookBook — Resept kitabı

CookBook yerli Azərbaycan reseptlərini nəzərdən keçirmək və TheMealDB vasitəsilə internetdən resept axtarmaq üçün hazırlanmış Next.js tətbiqidir.

## İmkanlar

- Reseptləri kateqoriyalara görə nəzərdən keçirmək
- TheMealDB-də yemək adına görə resept axtarmaq
- Resept detalları, inqrediyentlər və hazırlanma addımlarına baxmaq
- Porsiya sayını dəyişib inqrediyent miqdarlarını uyğunlaşdırmaq
- Hazırlanma addımlarını tamamlandıqca işarələmək
- Yüklənmə, xəta və tapılmayan səhifələri göstərmək

## Texnologiyalar

- Next.js
- React
- TheMealDB API
